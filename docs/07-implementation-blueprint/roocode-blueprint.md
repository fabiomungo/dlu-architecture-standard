# RooCode Implementation Blueprint

## Purpose

Provide RooCode with structured, versioned and testable implementation context.

## Required artifacts per capability

- `context.md`
- `requirements.md`
- `user-stories.md`
- `acceptance-tests.md`
- `file-tree.md`
- `api-contract.yaml`
- `events.yaml`
- `doctypes.yaml`
- `agent-contracts.yaml`
- `security.md`

## Implementation rule

RooCode must not infer business rules that are absent from the architecture repository. Missing rules are raised as RFCs or ADR candidates.
