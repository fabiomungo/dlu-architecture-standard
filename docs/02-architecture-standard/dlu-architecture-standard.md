# DLU Architecture Standard

## Mandatory viewpoints

Every major capability must be documented through:

1. Business motivation
2. Pedagogical rationale
3. Functional architecture
4. AI behaviour
5. Information model
6. Technical architecture
7. Governance and security
8. KPIs and observability
9. Implementation blueprint

## Core rules

- Domain-first, technology-second.
- Graph-native for knowledge and competency relationships.
- Event-driven integration.
- API-first interoperability.
- Human-in-the-loop for high-impact academic decisions.
- Tenant isolation by design.
- Explainability and provenance for AI recommendations.
- Reusable, versioned architecture artifacts.
