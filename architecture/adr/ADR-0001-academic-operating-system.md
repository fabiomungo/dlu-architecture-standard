# ADR-0001 — DLU as an Academic Operating System

Status: Accepted

## Context
Traditional LMS-centric architectures fragment the student journey and treat courses as the primary object.

## Decision
DLU will be designed as an Academic Operating System with a stable Academic Kernel, shared services, academic domains and role-based experiences.

## Consequences
- Shared domain models replace duplicated workspace data.
- Moodle and ERP components become runtimes or systems of record, not the whole platform.
- AI orchestration and graph services become first-class architecture components.
