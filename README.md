# DLU Architecture Standard

Official architecture repository for the **DLU AI-Native University** and its **Academic Operating System**.

This repository is the Single Source of Truth for:

- Academic philosophy and manifesto
- DLU Architecture Standard (DAS)
- Reference architecture
- DLU Builder Turnkey integration
- Student, Faculty, Builder and institutional experiences
- AI cognitive architecture and agent contracts
- Domain models, ontology and graph models
- APIs, events, Frappe DocTypes and workflows
- RooCode implementation blueprints

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
```

Open `http://127.0.0.1:8000`.
