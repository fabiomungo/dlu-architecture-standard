# DXA — DLU Experience Architecture

A lean, maintainable experience architecture for DLU. The EKG is the semantic engine; users interact with task-oriented projections (“lenses”), not with the full graph.

## Core UX equation
`Role + Intent + Context + Permission → Lens → Projection → View Model → UI`
