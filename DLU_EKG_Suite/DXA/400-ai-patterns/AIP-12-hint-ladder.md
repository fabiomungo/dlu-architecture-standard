# AIP-12 — Hint Ladder

## Purpose
Hints progress from conceptual cue -> structural cue -> partial step -> worked step. The UI always shows the hint level and does not penalize the learner invisibly. “Show another hint” is an explicit action.

## Required states
Default, loading, insufficient evidence, restricted, stale state, accepted, skipped.

## Accessibility
All reasoning and state conveyed visually must have equivalent text. No pedagogical status is encoded by color alone.
