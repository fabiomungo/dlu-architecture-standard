# Architecture Governance

## Roles
- Product Architecture Owner — DPA
- Knowledge/Graph Architect — DKA
- Experience Design Owner — DXA
- Solution/Platform Architect — DSA
- Domain Owners — academic, assessment, student, career, accreditation

## Change classes
- Patch: wording, examples, non-breaking metadata.
- Minor: additive component/entity/API/event.
- Major: breaking semantic, interaction or integration contract.

## Review gates
Discovery → Design Review → Architecture Review → Security/Privacy Review → Implementation Ready → Production Review.
