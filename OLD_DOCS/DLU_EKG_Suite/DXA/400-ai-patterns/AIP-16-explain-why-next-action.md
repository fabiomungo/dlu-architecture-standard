# AIP-16 — Explain Why This Next Action

## Purpose
Every adaptive recommendation exposes an explanation drawer with: current goal, relevant mastery/confidence, prerequisite relation, expected benefit and alternative. The student may accept, postpone or ask for an alternative.

## Required states
Default, loading, insufficient evidence, restricted, stale state, accepted, skipped.

## Accessibility
All reasoning and state conveyed visually must have equivalent text. No pedagogical status is encoded by color alone.
