# AIP-13 — Remediation

## Purpose
When a prerequisite gap or probable misconception is detected, explain why the Tutor is redirecting the learner. Provide a short remediation activity and a clear path back to the original goal.

## Required states
Default, loading, insufficient evidence, restricted, stale state, accepted, skipped.

## Accessibility
All reasoning and state conveyed visually must have equivalent text. No pedagogical status is encoded by color alone.
