# AIP-14 — Adaptive Difficulty

## Purpose
Increase or decrease task difficulty gradually based on mastery and confidence. Make changes explainable on request. Avoid labels such as “weak student”; show task readiness and progress.

## Required states
Default, loading, insufficient evidence, restricted, stale state, accepted, skipped.

## Accessibility
All reasoning and state conveyed visually must have equivalent text. No pedagogical status is encoded by color alone.
