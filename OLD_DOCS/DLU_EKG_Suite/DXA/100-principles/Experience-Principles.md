# DXA-100 — Experience Principles & Design Language

1. **Graph underneath, task-oriented views above.**
2. **Smallest useful projection.** Show only the information needed for the current decision.
3. **Progressive disclosure.** L0 Signal → L1 Explanation → L2 Evidence → L3 Local Graph.
4. **Role-based abstraction.** Student sees action/readiness; Faculty sees attainment/root cause; Dean sees curriculum health; Provost sees institutional risk and assurance.
5. **Mastery is not confidence.** Always preserve the distinction.
6. **Explain AI recommendations.** Every consequential recommendation exposes “why”, evidence and uncertainty.
7. **Evidence traceability.** KPIs must drill down to outcome and evidence where permissions allow.
8. **No ontology leakage.** Internal node names, IDs and edge labels are not UI copy.
9. **Accessible equivalent.** Every graph has a list/table/path alternative.
10. **Decision before visualization.** Pick the user decision first, then the visual pattern.
