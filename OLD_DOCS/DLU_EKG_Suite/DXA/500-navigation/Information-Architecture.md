# DXA-500 — Information Architecture & Navigation

Navigation is role-based but uses stable domain nouns. Global primitives: Home, Search, Work/Study, Evidence, Insights, AI Assistant, Profile/Settings. Dean/Provost receive portfolio and assurance destinations; students receive learning path and career destinations.

Use breadcrumbs for semantic drill-down: Program → Course → Outcome → Evidence. Local graph exploration is a secondary mode, never primary navigation.
