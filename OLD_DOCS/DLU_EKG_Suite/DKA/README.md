# DKA — DLU Knowledge Architecture

The canonical semantic architecture of DLU. DKA owns identifiers, ontology, competency/outcome semantics, evidence/mastery semantics, standards mapping and graph governance.

## Key rule
DLU canonical concepts remain stable; external frameworks (CASE, ESCO, SFIA, DigComp, EQF) are mapped through versioned external references rather than becoming the internal primary key space.
