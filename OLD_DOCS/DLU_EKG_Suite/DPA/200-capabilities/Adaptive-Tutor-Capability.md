# Adaptive Tutor Capability — ATA 1.0

## Product capability
**AI Learning & Tutoring**

Sub-capabilities:
- Adaptive Tutor
- Diagnostic Tutor
- Socratic Tutor
- Practice Tutor
- Assessment Tutor (bounded, policy-controlled)
- Learning Advisor
- Career Learning Advisor

## User outcomes
- Receive explanations aligned to current knowledge state.
- Get the next best learning action rather than generic recommendations.
- Repair prerequisite gaps before they block progress.
- Understand why a recommendation was made.
- See mastery evolve from evidence, not from chat activity alone.

## Product guardrails
Tutor may recommend but cannot silently alter official curriculum, grades or academic records. High-stakes decisions remain in governed assessment/academic workflows.
